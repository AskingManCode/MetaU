# Microservicio de Bitacoras - GEN1

Microservicio encargado del registro y consulta de bitacoras del sistema MetaU.

## Historia de usuario

GEN1 - Registro y consulta de bitacoras.

El servicio permite registrar las acciones realizadas por los usuarios y consultar las bitacoras almacenadas.

## Tecnologias

- .NET 10
- Minimal API
- SQL Server
- Microsoft.Data.SqlClient
- Autenticacion mediante Bearer Token
- Integracion con MicroservicioLogin
